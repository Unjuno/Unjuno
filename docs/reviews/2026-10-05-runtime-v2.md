## Evidence boundaries and follow-up risks

The visual direction is a design judgment. No first-time human-viewer experiment has been conducted; the claim that viewers mistake it for a native GitHub feature remains untested.

The displayed GIF is a replay, not streaming game output. Snapshot metadata describes the last persisted input, not engine health or proof of successful movement. Camo caching can delay updates; the versioned layout filenames solve this layout migration, not all future refreshes. The open profile does not live-refresh when another visitor sends a command.

This iteration did not change or recertify the shared game engine, input injection, save correctness, queue ordering, simultaneous deployment behavior or abuse controls. Prior save-file changes and green workflows alone must not be promoted into an exactly-once/game-correctness guarantee. Those need separate end-to-end tests before making stronger operational claims.

Physical iOS/Android browsers, all GitHub contrast themes, screen readers and subjective first-impression performance remain untested.
